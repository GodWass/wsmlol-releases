# WSMLol — téléchargements

Application compagnon gratuite pour League of Legends (champ select : suggestions de pick, fiche matchup, profil). Ce dépôt ne contient que les **installeurs** et les fichiers de **mise à jour automatique** ; le code source est privé.

## Installer

1. Ouvre la page [Releases](https://github.com/GodWass/wsmlol-releases/releases/latest).
2. Télécharge :
   - **Windows** : `WSMLol_x.y.z_x64-setup.exe` (recommandé) ou le `.msi` ;
   - **macOS** : le `.dmg`.
3. Lance l'installeur.

L'app n'est pas encore signée numériquement :

- **Windows** : SmartScreen peut afficher « Windows a protégé votre ordinateur ». Clique sur **Informations complémentaires**, puis **Exécuter quand même**.
- **macOS** : clic droit sur l'app, puis **Ouvrir**.

## Mises à jour

L'app vérifie les nouvelles versions au démarrage et les propose dans **À propos**. Rien à retélécharger à la main.
